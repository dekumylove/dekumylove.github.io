Welcome to my personal homepage! This is the first blog post, giving a quick introduction to how this site was built.

## Tech Stack

This site is built with **Astro**, a modern static site generator. Here's the tech stack:

- **Astro** — Static site framework, zero JavaScript by default
- **Tailwind CSS** — Utility-first CSS framework
- **Preact** — Lightweight interactive components
- **GitHub Pages** — Free hosting

## Why Build a Personal Site?

As a tech professional, having my own homepage allows me to showcase academic achievements and share technical thoughts. The couple's activity recommendation module is a feature I'm particularly excited about — helping people discover fun things to do together.
